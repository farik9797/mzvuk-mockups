# М-ЗВУК — концепции дизайна сайта

Три концепции главной страницы интернет-магазина музыкальных инструментов
и звукового оборудования (ООО «Арт-Медиа Трейд», mzvuk.by), собранные по брифу
на разработку коммерческого сайта.

- **[Все концепции](index.html)** — сравнение, палитры, покрытие брифа
- [Концепция 1 «Прилавок»](concept-1-prilavok.html) — светлая плотная витрина
- [Концепция 2 «Сцена»](concept-2-scena.html) — тёмная pro-audio
- [Концепция 3 «Мастерская»](concept-3-masterskaya.html) — editorial, кремовая

Товары, цены, отзывы и новости — примеры для демонстрации вёрстки.
